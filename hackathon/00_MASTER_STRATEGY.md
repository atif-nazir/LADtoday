## WHY SUPABASE EDGE FUNCTIONS WIN WITH JUDGES

Supabase Edge Functions run on Deno at the edge — this is important for the hackathon because:

1. **Zero cold start latency** — agents respond fast in demo
2. **Built-in secrets management** — no exposed Bright Data tokens
3. **PostgreSQL database** — agent memory, article storage, audit logs all in one
4. **Realtime subscriptions** — dashboard updates live as agents run
5. **Row Level Security** — judges see "enterprise-grade" immediately

Each agent = one Supabase Edge Function. The orchestrator chains them.
